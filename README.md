# ♟️ Our Chess Adventure

A kid-friendly interactive guide for learning chess together — parent + child, side by side. 9 lessons from the basics to playing a full game.

## Deploy to GitHub Pages

1. Create a new GitHub repo named `chess-adventure`
2. Push this code to the `main` branch
3. Go to **Settings → Pages → Source** → select **GitHub Actions**
4. Auto-deploys at `https://<username>.github.io/chess-adventure/`

## Local Development

```bash
npm install
npm run dev
```
